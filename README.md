For contract work, I work through my own company, [Pharosyne Tech](https://pharosyne.tech).

## Open source

- [nahuali](https://github.com/Arakiss/nahuali): memory for agents, with a local ledger you can audit.
- [llm-router-bench](https://github.com/Arakiss/llm-router-bench): measures what an LLM router saves compared with sending everything to one expensive model.
- [galdr](https://github.com/Arakiss/galdr): records the tool calls an agent made on a task and turns them into a skill it can replay. Runs on your machine.
- [vestig](https://github.com/Arakiss/vestig): structured logging for TypeScript. It removes personal data from logs by itself and works on different runtimes.
- [slod](https://github.com/Arakiss/slod), formerly traceframe: local traces for AI agent runs. The trace is append-only, so you can check later what really happened.
